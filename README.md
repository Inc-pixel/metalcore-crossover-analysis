# Metalcore Crossover Analysis

Research question: When a metalcore song goes mainstream, what musical features change and how did that affect their popularity?

## Dataset
Around 30 albums across 15 different bands, manually annotated for breakdown amt., vocal style, electronic production, guitar complexity, dropped tuning, and lyrical theme.

## Tools
Python, pandas, seaborn, scikit-learn
